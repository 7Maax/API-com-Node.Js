Sobre

A Vitrine Tech é um catálogo de produtos de informática feito como trabalho acadêmico. As páginas usam HTML, CSS, Bootstrap e JavaScript e conversam com uma API própria em Node.js por meio do fetch: listam os últimos produtos cadastrados, mostram os detalhes de cada um e permitem cadastrar, editar e excluir itens.
